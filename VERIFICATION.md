Installer содержит offline-установщик WebView2. Standalone EXE использует WebView2, установленный в системе. Rust бизнес-логики не содержит. Разрешения Tauri проверены реальным запуском; по результатам проверки добавлено необходимое разрешение `core:window:allow-get-all-windows`.

## Проверенные сценарии

Ivan/Petr, 5 минут, отдельное табло без кнопок, +2/+4, advantage/penalty, Undo/Redo, Pause, 04:00, Resume, закрытие и новый запуск, восстановление, синхронизация и окончание времени. Также проверены ввод имён, BJJ actions, подавление автоповтора и shortcuts в диалогах, подтверждения submission и New Match.

Русская локаль проверена на основном и зрительском окне, включая переключение языка без перезапуска. Чекбоксы звуков проверены независимо: выключенные сигналы не создают аудиоисточников; включённые воспроизводятся на соответствующих переходах. Продолжение после паузы не повторяет стартовый сигнал. Настройки сохраняются при перезагрузке.

Визуально просмотрены основные экраны и настройки. На 1366×768 и 1920×1080 проверено отсутствие вертикальной прокрутки. Русский основной экран и настройки проверены на 1366×768. Снимки находятся в `test-results/`.

## Границы проверки

Установщик собран, но его установка на чистых Windows 10/11 не выполнялась. Native fullscreen и перемещение проверены на доступном мониторе; физический второй монитор не требовался для этой проверки. Реальную громкость следует отрегулировать на оборудовании соревнования. EXE и installer не подписаны сертификатом.

При первоначальной настройке окружения установлены Rust/Cargo, Microsoft C++ Build Tools и Windows SDK. Ошибка нехватки места была устранена после освобождения диска пользователем. Финальная native-сборка завершилась успешно. Единственное предупреждение линкера — информационное сообщение MSVC о создании import library, не ошибка сборки.

`npm audit` сообщает 2 moderate findings в dev-зависимостях Vitest / @vitest/mocker (GHSA-82fw-gwwq-j7x9). Они не входят в production bundle; тесты выполняются через `vitest run`, без сервера browser mock. Автоматическое несовместимое обновление не применялось.
