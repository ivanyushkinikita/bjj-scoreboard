# Установка Tatami Scoreboard

Приложение для судейства БЖЖ и греплинга. Интерфейс на русском языке, работа без интернета.

## Что потребуется

- Компьютер с Windows 10 или Windows 11, 64-разрядная система (x64).
- Для зрительского табло — дополнительный монитор, телевизор или проектор, подключённый к компьютеру.
- Для звуковых сигналов — включённые динамики или внешняя акустика.

Node.js, Rust и инструменты разработчика устанавливать не нужно.

## Установка

1. Найдите установщик:

   ```text
   F:\Experiments\bjj-scoreboard\src-tauri\target\release\bundle\nsis\Tatami Scoreboard_1.0.0_x64-setup.exe
   ```

2. Для установки на другой компьютер скопируйте **этот один файл**, например на флешку. Папка проекта не требуется.
3. Запустите установщик двойным щелчком и следуйте указаниям мастера установки.
4. После установки откройте **Tatami Scoreboard** через меню «Пуск».

Установщик содержит необходимый компонент Microsoft Edge WebView2 и устанавливает его при необходимости. Для установки из этого пакета и работы приложения интернет не требуется.

Сборка не подписана цифровым сертификатом. Если Windows покажет предупреждение о неизвестном издателе, продолжайте только для установщика, полученного из доверенного источника. Если доступно, выберите «Подробнее» → «Выполнить в любом случае». Отключать защиту Windows не нужно; на управляемом компьютере при блокировке обратитесь к администратору.

## Первый запуск

1. Откройте **«Настройки»** в правом верхнем углу.
2. Выберите правила: **БЖЖ / IBJJF** (по умолчанию), **Греплинг / UWW** или **свои правила**. Для стандартных правил задайте возрастную категорию и, где доступно, пояс.
3. Проверьте чекбоксы звуков старта и окончания. Нажмите кнопки проверки звуков и настройте громкость компьютера.
4. Закройте настройки, введите имена спортсменов и выберите их цвета: красный, синий или белый.
5. Проверьте длительность схватки. Она подставляется по выбранным правилам, но её можно изменить вручную.
6. Нажмите **«Создать схватку»**. Таймер пока не идёт. Для запуска нажмите **пробел** или кнопку **«Запустить таймер»**.

Выбор правил после начала схватки блокируется. Для другого набора правил создайте новую схватку и откройте настройки.

## Зрительское табло на втором экране

1. Подключите монитор, телевизор или проектор.
2. В Windows нажмите **Win + P** и выберите **«Расширить»**.
3. В приложении нажмите **«Открыть зрительское табло»**.
4. Откройте **«Настройки» → «Настройки табло»**, выберите нужный монитор и включите полноэкранное зрительское табло. Окно также можно перетащить мышью.

Управляйте счётом из основного окна. Цвета, таймер, счёт и заставка победителя синхронизируются автоматически.

## Основные клавиши

| Клавиша | Действие |
|---|---|
| Пробел | Старт, пауза, продолжение таймера |
| Backspace | Сброс таймера с подтверждением |
| Ctrl + Z | Отменить последнее начисление |
| Ctrl + Shift + Z | Повторить отменённое начисление |
| F11 | Полноэкранный режим основного окна |

Полный список доступен по кнопке **«Клавиши»**. При вводе текста и в открытых диалогах горячие клавиши управления схваткой не действуют.

## Запуск отдельного EXE

Если WebView2 уже установлен на компьютере, можно запускать приложение без мастера установки:

```text
F:\Experiments\bjj-scoreboard\src-tauri\target\release\tatami-scoreboard.exe
```

Если отдельный EXE не запускается из-за отсутствия WebView2, используйте установщик из раздела «Установка».

## Если нет звука

- Проверьте чекбоксы в настройках приложения и кнопки проверки звуков.
- Убедитесь, что громкость приложения не выключена в микшере Windows.
- Проверьте выбранное устройство вывода: после подключения HDMI звук может выводиться на телевизор или монитор.
- Стартовый гонг звучит при первом запуске таймера и после его сброса. Продолжение после паузы не повторяет сигнал.

## Сохранение и повторный запуск

Приложение сохраняет схватку и настройки локально. Если при запуске предложено восстановление, выберите **«Восстановить схватку»** или **«Начать новую схватку»**.

Если закрыть приложение с работающим таймером, при восстановлении будет учтено время, прошедшее после закрытия. Чтобы остановить отсчёт перед выходом, сначала поставьте таймер на паузу.
