# Установка Tatami Scoreboard

Приложение для судейства БЖЖ и греплинга. Интерфейс на русском языке, работа без интернета.

## Что потребуется

- Компьютер с операционной системой и архитектурой, для которых опубликована сборка приложения.
- Для зрительского табло — дополнительный монитор, телевизор или проектор, подключённый к компьютеру.
- Для звуковых сигналов — включённые динамики или внешняя акустика.

Node.js, Rust и инструменты разработчика устанавливать не нужно.

## Установка

1. Откройте [страницу релизов Tatami Scoreboard](https://github.com/ivanyushkinikita/bjj-scoreboard/releases/latest).
2. В разделе **Assets** выберите пакет для своей операционной системы и архитектуры. Архивы **Source code** содержат исходники, а не готовое приложение.
3. Скачайте пакет и следуйте инструкции для его формата, указанной в описании релиза. Для переноса на другой компьютер можно использовать флешку; папка проекта не требуется.
4. Откройте **Tatami Scoreboard** из списка приложений вашей системы.

Сейчас опубликован установщик для **Windows 10/11 x64**: файл **Setup.exe**. Он включает WebView2; интернет для установки из этого пакета и работы не требуется. Готовые пакеты для других систем в текущем релизе не опубликованы. Системные требования и особенности установки смотрите в описании выбранного релиза.

## Первый запуск

1. Откройте **«Настройки»** в правом верхнем углу.
2. Выберите правила: **БЖЖ / IBJJF** (по умолчанию), **Греплинг / UWW** или **свои правила**. Для стандартных правил задайте возрастную категорию и, где доступно, пояс.
3. Проверьте чекбоксы звуков старта и окончания. Нажмите кнопки проверки звуков и настройте громкость компьютера.
4. Закройте настройки, введите имена спортсменов и выберите их цвета: красный, синий или белый.
5. Проверьте длительность схватки. Для новой схватки сохраняется длительность предыдущей. При смене правил подставляется время по категории. Время можно ввести вручную или изменить кнопками ▲ / ▼ либо стрелками вверх/вниз на клавиатуре: поставьте курсор до двоеточия для изменения минут или после двоеточия для изменения секунд. Так же работает поле оставшегося времени во время схватки.
6. Нажмите **«Создать схватку»**. Таймер пока не идёт. Для запуска нажмите **пробел** или кнопку **«Запустить таймер»**.

Выбор правил после начала схватки блокируется. Для другого набора правил создайте новую схватку и откройте настройки.

## Дополнительное время при равном счёте

После окончания основного времени при равенстве баллов открывается окно настройки дополнительного времени. Задайте длительность вручную или стрелками по положению курсора и нажмите **«Установить дополнительное время»**. По умолчанию — 01:00. Для запуска нажмите пробел или кнопку запуска таймера.

Дополнительный таймер занимает место основного. В левом верхнем углу области таймера остаются зафиксированное основное время и его исходная длительность. Оба окна показывают одинаковые данные. Пауза, редактирование и сброс работают с дополнительным таймером; основное время сохраняется. После перезапуска можно восстановить оба таймера, а для новой схватки сохраняется длительность основного времени.

Окно можно отменить и снова открыть кнопкой **«Настроить дополнительное время»**. В режиме UWW также выберите атакующего; правила определения результата этого режима сохраняются. Дополнительное время назначает судья по регламенту соревнования.

## Зрительское табло на втором экране

1. Подключите монитор, телевизор или проектор.
2. В настройках экранов операционной системы включите расширение рабочего стола на дополнительный экран.
3. В приложении нажмите **«Открыть зрительское табло»**.
4. Откройте **«Настройки» → «Настройки табло»**, выберите нужный монитор и включите полноэкранное зрительское табло. Окно также можно перетащить мышью.

Управляйте счётом из основного окна. Цвета, таймер, счёт и заставка победителя синхронизируются автоматически.

## Основные клавиши

| Клавиша | Действие |
|---|---|
| Пробел | Старт, пауза, продолжение таймера |
| Backspace | Сброс таймера с подтверждением |
| Ctrl + Z | Отменить последнее начисление |
| Ctrl + Shift + Z | Повторить отменённое начисление |
| F11 | Полноэкранный режим основного окна |

Полный список доступен по кнопке **«Клавиши»**. При вводе текста и в открытых диалогах горячие клавиши управления схваткой не действуют.

## Если нет звука

- Проверьте чекбоксы в настройках приложения и кнопки проверки звуков.
- Убедитесь, что громкость приложения не выключена в настройках звука операционной системы.
- Проверьте выбранное устройство вывода: после подключения HDMI звук может выводиться на телевизор или монитор.
- Стартовый гонг звучит при первом запуске таймера и после его сброса. Продолжение после паузы не повторяет сигнал.

## Сохранение и повторный запуск

Приложение сохраняет схватку и настройки локально. Цвета участников и заданная длительность остаются для следующих схваток, в том числе после перезапуска. Свои действия с баллами доступны в «Настройки» → «Мои сохранённые правила»; для их записи нажмите «Сохранить правила» в редакторе. Если при запуске предложено восстановление, выберите **«Восстановить схватку»** или **«Начать новую схватку»**.

Если закрыть приложение с работающим таймером, при восстановлении будет учтено время, прошедшее после закрытия. Чтобы остановить отсчёт перед выходом, сначала поставьте таймер на паузу.
