# Tatami Scoreboard

Приложение для судейства БЖЖ и греплинга: React, TypeScript, Zustand, Tauri 2.

## Структура

- `src/domain/` — правила, счёт, таймер и определение победителя.
- `src/stores/` — состояние схватки и настройки.
- `src/components/` и `src/app/` — интерфейс и переводы.
- `src/services/` — сохранение, звук и отдельное зрительское окно.
- `src-tauri/` — нативная оболочка и конфигурация упаковки.
- `e2e/` — браузерные сценарии Playwright.

## Работа с проектом

- Сохраняйте автономную работу приложения без интернета.
- Учитывайте оба языка интерфейса и синхронизацию основного и зрительского окон.
- Цвет спортсмена берите из состояния схватки; не привязывайте цвет к стороне A или B.
- Сохраняйте совместимость локально сохранённых схваток и настроек.
- Проверяйте интерфейс на размерах 1000×680, 1366×768 и 1920×1080; элементы управления и счёт не должны перекрываться.
- Не добавляйте абсолютные пути компьютера в пользовательскую документацию. Указывайте только реально доступные сборки для платформ.

## Проверки и сборка

- `npm test` — тесты логики.
- `npm run test:e2e` — браузерные сценарии.
- `npm run build` — проверка TypeScript и production-сборка интерфейса.
- `npm run tauri build` — нативная сборка; требует инструменты целевой платформы. Текущая конфигурация пакует Windows NSIS installer.
- `scripts/native-smoke.mjs` изменяет сохранённую схватку в профиле приложения: используйте только тестовый профиль, не затрагивая пользовательские данные.
- Сгенерированные сборки, отчёты тестов, локальные инструменты и секреты не коммитьте.
- При публикации релиза проверяйте соответствие исходников, тега и артефактов, контрольные суммы и доступность скачивания.
