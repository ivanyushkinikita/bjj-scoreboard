# Referee quick guide

## Installation

Download the installer from the project's Releases page, run it, and choose English or Russian. You can change the application language later in Settings.

## Single match

1. On the home screen, choose **Single match**.
2. Enter the athletes, select their colours and rules, and set the duration in `MM:SS` format. A zero duration is changed to one second.
3. Create the match, start the timer, and record scoring actions on the referee screen.
4. Confirm the result when the match finishes. A regular match can end in a draw when the score is tied.

## Tournament

1. Choose **Tournament**, add athletes, and set the match duration and athlete colours.
2. For a single-elimination tournament, place athletes in the first round manually or randomly. An empty pairing is not created; an athlete without an opponent receives a bye into the next round.
3. For a round-robin tournament, select **Start tournament** after adding athletes. In list view, drag the handle to swap a pairing; in table view, select a match at the athletes' intersection.
4. Open a pairing, run the match, and confirm its result. In single elimination, the winner advances; in round robin, the standings update.
5. After all matches are complete, select **Finish tournament** to return to the home screen.

## Settings and history

- **Settings** lets you change the language, light or dark theme, rules, and start/end gong sounds.
- Use **Match history** or the completed-match screen to export a CSV file. It includes the athlete name, score change, and time of each scoring event; its default filename contains both athletes' names.
- The result-confirmation dialog can be dismissed with its close button, **Cancel**, or a click on the backdrop, returning to the timer without confirming the result.

## Helpful notes

- From a tournament match, you can return to the bracket and choose whether to stop the timer.
- Completed single-elimination pairings cannot be edited; unfinished pairings remain editable.
- Open the synchronized spectator window from Settings and move it to the desired display before enabling fullscreen.
- The application works locally: no internet connection is required for refereeing or saving current data.
